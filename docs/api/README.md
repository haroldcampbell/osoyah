# API Docs

Backend read endpoints for the FastAPI service. Base path for all endpoints: `/api`.

## Index

- `docs/api/openapi.json` - Canonical OpenAPI contract (export via `python backend/scripts/export_openapi.py`).
- `docs/api/endpoint-mapping.md` - Index for endpoint mappings by domain.
- `docs/api/boards-endpoint-mapping.md` - Board endpoints mapped to frontend usage and data needs.
- `docs/api/lists-endpoint-mapping.md` - List endpoints mapped to frontend usage and data needs.
- `docs/api/cards-endpoint-mapping.md` - Card endpoints mapped to frontend usage and data needs.
- `docs/api/relationships-endpoint-mapping.md` - Relationship endpoints mapped to frontend usage and data needs.
- `docs/api/boards-api-output.md` - Canonical backend API docs for boards.
- `docs/api/lists-api-output.md` - Canonical backend API docs for lists.
- `docs/api/cards-api-output.md` - Canonical backend API docs for cards.
- `docs/api/relationships-api-output.md` - Canonical backend API docs for relationships.
