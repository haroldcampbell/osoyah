# UX Patterns

## Purpose
Provide concrete UX patterns and copy guidance so UI feedback is consistent across features.

## Toasts (Success + Error)
- Use self-dismissing toasts for both success and failure of state-changing actions.
- Place toasts in the top-right of the viewport to avoid blocking primary actions.
- Keep copy short and specific; prefer past tense on success and clear remediation on failure.
- Duration: 2.0 to 3.0 seconds; errors may stay slightly longer but must auto-dismiss.

### Examples
- Success: "Board settings saved."
- Success: "Card moved to Done."
- Error: "Unable to save board settings."
- Error: "Failed to move card. Try again."
