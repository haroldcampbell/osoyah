# 04-001 Gaps to Consider (Not Yet Standardized)

## Confirmations
- Confirmations mix native `window.confirm` and custom modals; consider unifying on a modal pattern.

### Examples
- `client/src/app/board/list/board-list.component.ts`
- `client/src/app/board/board-toolbar/board-toolbar.component.ts`

## Toast Coverage
- Toast usage is not universal; many flows rely on inline errors only.
- Consider a consistent success/error feedback rule beyond settings saves.

## Problem / Goal
Highlight inconsistent or missing UX conventions to guide future alignment.
